# ZM-F 风格方法论（ZMF 六层提示词体系）

> 来源：ZM-F 壁纸 364 镜逐镜解析（三轮机器+人工精读）+ 反推实践 296 条验证。
> 本文档是 ZM-001~005 风格、C-37~C-42 色系、ZL-001~010 构图、scenes.json 场景库的**方法论底座**。

## 一、六层画面细节法则（每条提示词必须逐层兑现）

1. **取景视角、机位与空间骨架**：镜头焦段感、视点高度（微仰/平视/俯瞰）、视心偏置位置（如画面右三分之一）、焦点主体与边缘裁切。⚠️ 绝不写画幅比例数字，构图完全由景别与视点表达。
2. **主体容貌、神态与骨骼微表情**：眼型、眼睑张力、睫毛投影、眉骨阴影、唇色与开合、发丝分界与风向贴附。
3. **服装剪裁、重力与动态张力**：织物厚度与纹样、受力褶皱方向、飘带/披帛的空气动力学、边缘透光。
4. **环境拓扑、景深与配角配置**：前景遮挡、中景主体、背景纵深；配角数量与景深模糊度。
5. **光源追踪与材质反应**：主光/侧逆光/环境漫射的方向与色温；皮肤次表面散射、织物半透明、金属高光、石木反馈。
6. **空气介质、色调与成像签名**：悬浮尘埃/花瓣/雾气；冷暖撞色的区域分布；焦外光斑、暗角、颗粒。

## 三、句法十二则（MJ 语法移植，中文同理）

世界声明句开头 / Central subject 前置 / 人物逐一点名 / 尺度关系句（人物占比百分比）/ 防崩三件套（面部解剖、自然手部、真实皮肤）/ **色板名词化**（celadon glaze、vermilion、gold leaf 等材质色名）/ sheen 对仗（controlled X, not Y）/ Behind: 标签 / 光照三连（暗部写位置）/ 云景分层配色 / 呼吸口 / 两词收尾。
分隔符分工：逗号=并列属性，破折号=限定对仗，分号=景深分层。

## 四、反推固定流程（源帧 → 提示词）

1. 看源帧（`stills/<BV>/sNN_mid.jpg`），按六层逐层观察
2. 定锚点：must_keep / may_enhance / must_avoid
3. 按六层写中文正文（中央主体前置、色板名词化、景深分层）
4. 字幕、水印、手机 UI 一律不入词
5. 出图后与源帧比色板（k-means 占比差）→ 回改对应句

## 五、铁律

- 只写终态，禁过程词（"褪去原有/换上/不再是"）
- 禁指代词（"如图/保持不变"）
- 禁抽象形容词（"唯美/仙气/电影感"→ 转译为瞳孔反光、下颌紧绷、衣角受力、景深模糊阶梯）
- 排除元素写进正向的肯定句限定（"X, not Y" 对仗），不用"不要 X"
- 一次只动一个变量迭代
